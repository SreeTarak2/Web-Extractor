==================================================
TYPE RULES (STRICT)
==================================================
Choose EXACTLY ONE from this list:
"contest" | "hackathon" | "grant" | "fellowship" | "award" | "challenge"

Rules:
- "contest" → open competition with judged submissions
- "hackathon" → time-boxed collaborative build event
- "grant" → funding awarded without competitive judging
- "fellowship" → paid program with mentorship/residency component
- "award" → recognition prize, typically nominated not applied
- "challenge" → problem-solving competition, often tech-focused
- Default to "contest" if unclear

==================================================
FLAGS RULES (STRICT)
==================================================
flags is an array of string labels. Only use values from this list:

"women" → contest is EXCLUSIVELY restricted to women
           (female-identifying participants only).
           Do NOT set if open to any other gender.

"broken-link" → official link is confirmed unreachable.

Rules:
- Empty array [] is the default — do not add flags speculatively
- NEVER add flags not in the list above
- NEVER add "women" unless the contest explicitly prohibits
  participation by non-women

DESCRIPTION RULES (STRICT)
==================================================
- 120–300 characters
- 1–3 sentences
- Neutral, informational tone
- No hype, history, prizes, dates, or eligibility
- Summarize aggressively if source text is verbose

==================================================
SKILL LEVEL RULES (DETERMINISTIC)
==================================================
Allowed values:
["beginner", "intermediate", "advanced"]

skillLevels (range):
- Open to all → all three
- Students / early-stage → beginner + intermediate
- Professionals / researchers → intermediate + advanced
- Elite-only → advanced only
- Unclear → ["intermediate"]

primarySkillLevel (ONE ONLY):
Decision order:
1. Explicitly stated → use it
2. Researchers / professionals → advanced
3. Students / pitching → intermediate
4. Explicit beginner → beginner
5. Else → intermediate

primarySkillLevel MUST exist in skillLevels.

==================================================
ELIGIBILITY STRUCTURE RULES
==================================================
DO NOT compress eligibility into one string.

participantType allowed values:
["students", "recent_graduates", "researchers", "startups", "individuals", "teams", "companies"]

graduationAfter:
- Only if explicit
- Format: "YYYY-MM"

teamSize:
- Extract numeric min/max if present

eligibilityLabel:
- ≤ 60 characters
- High-level only
- NO dates, NO team sizes, NO parentheses

eligibilityDetail:
- 1–2 sentences clarifying constraints

==================================================
MODE RULES (STRICT)
==================================================
audience.mode allowed values ONLY:
"online" | "offline" | "in-person" | "hybrid"

- "online" → fully remote, virtual participation
- "offline" → physical presence required (use "in-person" if clearer)
- "in-person" → physical attendance at a venue
- "hybrid" → both online and in-person options offered
- Default to "online" if unclear

NEVER output: "virtual", "physical", "remote", or any other value.

==================================================
PRIZE RULES (EVIDENCE-BASED)
==================================================
originalAmount: the raw number from source (in stated currency)
totalUSD: USD equivalent (convert if currency is known; else same as originalAmount)
currency: ISO code e.g. "USD", "EUR", "INR" — default "USD" if not stated

Classification:
1. Explicit amount → isMonetary = true, fill originalAmount + totalUSD
2. Monetary mentioned, no amount → isMonetary = true, both amounts = 0
3. Only non-monetary → isMonetary = false, both amounts = 0
4. No prize info → isMonetary = null, both amounts = 0

NEVER infer money.

DEADLINE EXTRACTION (ANTI-CONFUSION RULE)
==================================================

VALID:

INVALID:

If deadline cannot be unambiguously linked:
→ set ALL timeline fields to null

==================================================
TIMEZONE RULES
==================================================
1. If organizer city/country is explicit → map timezone
2. If unclear or international → organizerTimeZone = "UTC"
3. If date exists but no timezone:

   - Set organizerTimeZone = "UTC"

NEVER invent timezones.
